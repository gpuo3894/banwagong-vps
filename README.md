## 搬瓦工購買前要檢查哪些限制？

搬瓦工是 **self-managed VPS**。官方頁面列出 root access、KiwiVM、作業系統重裝、rDNS、快照和自動備份等功能，但伺服器內的系統更新、網站部署、防火牆、資料庫和安全設定，仍需要使用者自己處理。

購買前建議確認以下幾點：

1. **你是否能管理 Linux 伺服器**
   不熟悉 SSH、SSH 金鑰、systemd、Nginx 或防火牆的使用者，可能會把時間花在維護，而不是使用服務。

2. **需要多少流量與儲存空間**
   影音、備份、映像檔和大型資料庫會快速消耗流量與 SSD。只看 RAM 容量容易低估實際成本。

3. **是否需要特定路由**
   CN2 GIA、E-Commerce、香港、日本等方案的價格差異，主要反映網路路線和服務定位，不只是硬體配置差異。

4. **是否需要 IPv6**
   Dubai E-Commerce 方案的官方說明標示不支援 IPv6；如果你的應用環境需要 IPv6，應在購買前排除這類方案。

5. **是否需要 SLA 或更換 IP**
   部分特殊套餐會列出 99.99% SLA 或定期免費更換 IP 等條件，但這些條件不一定套用到所有標準方案。
